39 APS working set — direct links to e-Publishing where confirmed. Green badge = link path confirmed working as of its verify date. Amber badge = number not yet confirmed on a stable path, routes to e-Pubs search instead.
Why there's no auto-sync button: tested pulling e-Publishing's static file server directly — it sits behind Akamai bot protection and returned 403 Forbidden even with a normal browser identity, and it sends no CORS headers a page would need to read the response anyway. A button claiming to "auto-check for updates" would silently fail or lie about having checked. Instead: each card has a Verify Now button (opens real e-Pubs search) and a Mark Verified button you press after actually reading the cover page — that timestamp saves in this browser so you have a real audit trail, not a fake one.
